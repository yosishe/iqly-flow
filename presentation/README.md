# IQly conversion case study

A supplemental presentation explaining the submitted conversion flow, documented decisions and three proposed A/B tests. The 36 slides first explain the visitor flow and conversion, then develop the decision reasoning. Slides 1–20 form the main narrative, followed by a detailed decision appendix and submission links. Major choices include the mechanism, credible alternatives, tradeoffs, evidence limits and conditions for revision.

The original offline quiz release remains pinned at 3598613f4d84a57df274867067aeb49c25bfdbe9. This folder is a supplemental presentation release. It does not change the original flow files or ZIP. Its own MANIFEST.sha256 covers the presentation files. The last slide contains all eleven original public reviewer links.

All product screenshots were captured from the submitted public prototype using synthetic demo input. The creative images are the supplied exports. Text, tables and links are editable in the PowerPoint. The browser presentation and PDF derive from the same content/layout model in deck-content.mjs. Speaker notes and the browser notes panel identify sources. Reading view presents the full explanation at a readable size. The section menu separates the main narrative, decision detail and submission links.

Accounts are local simulations. IQ ranges and ranks are illustrative. The experiments and any numerical tradeoff example are prospective or hypothetical. No production conversion, user-study or psychometric result is claimed.
