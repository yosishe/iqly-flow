## What AI got wrong and how it was caught (where AI output was most dangerous, and the control used)
Fabricated citations → every claim carries a URL/DOI and agents were told to write "no reliable data" rather than guess. Unsupported behavioral claims → confidence labels and an explicit list of CRO folklore contradicted by evidence. Ambiguous puzzles and wrong keys → blind solve by a second agent before comparing keys. Misleading scientific copy → psychometrics review set the claim boundaries (band not number; no per-area profile). Inaccessible SVGs → neutral alt text that names the task without leaking the rule, plus an honest statement of the visual-only limit. Superficially isolated experiments → generated from one template, diffed. Hidden external dependencies → grep and offline e2e. Over-complicated code → no framework, no build step for running; one file per experience. In v5: a fold launcher that mis-measured by a scrollbar's width (row 39) → cross-check with a second renderer; a review pass that at first took the private staging for the newer copy → commit dates settled it; a PDF library that failed to import on a broken system package → the binding was repaired rather than the page-count check skipped.

## What a human decided
In v1: the constraints, the working hypothesis, the refusal to show an IQ number, the ad angle (real item, not clickbait), and every place where the honest answer was "we don't know yet". In v2: to upgrade rather than rebuild, to reopen the control decision with no default, to review the break-even and adopt the flip to the disclosed gate, and to prepare a live link. In v3: to replace the third test with signup-first, to keep the "~5 min" qualifier as a declared estimate, to keep the labelled provisional rank, and to state the AI/human split precisely. In v3.1: to gather four more research inputs and have them absorbed; the plan (keep the three tests, capture device and keyword segments, state a labelled sizing illustration, widen the Test 1 margin) was approved as written, and no input was allowed to overrule a decision, only to sharpen a test. In v4: to commission an independent audit, to authorise changing any earlier decision it attacked, and to approve the plan that kept the three tests and the control, tightened every claim, added the missing behaviours, and made one public repository the canonical package. The AI argued both sides of the gate decision, wrote the break-evens, built and tested every artifact, verified the audit against the code, and had its items and write-ups attacked by separate passes; it did not make the calls listed here.

## Final readiness work — Codex, without Cody

The user authorized preservation of the existing concept and portfolio, a private preparation repository, tested public corrections, and no external submission. Codex reproduced an answer/Skip race in a real browser, found stale callback and malformed-state recovery problems, and made deletion reachable during retakes and insufficient results. It also found a hidden-style conflict in the debug panel, corrected local-account promises, refit the vertical creative, and replaced the old private-layout packaging dependence.

Codex reconstructed historical research before correcting the 16/19 prevalence claim, unsupported psychometric transfers, denominator inconsistencies and treatment-dependent speed exclusions. It recomputed interval-boundary sizing, exposed the strict Test 3 quality policy's power limitation, re-rendered the artifacts and ran fresh release checks. These are AI discoveries. The user supplied the direction and authorized the corrections; this audit does not claim the user personally discovered each defect or conducted user interviews.

What earlier AI and human review missed: the old 32-case suite did not exercise rapid answer/Skip/Back, its allwrong case actually retained one correct answer, the vertical CSS rectangle did not contain all the artwork, and plausible strategic language was sometimes presented more strongly than its evidence allowed. No user research, commercial result, production randomization or norming study has been performed.
